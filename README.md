# PROJETO C.U.I.D.A

### Conexão Única de Integração de Dados Assistenciais

O **C.U.I.D.A** é um projeto acadêmico desenvolvido na **CESAR School**, na disciplina **Projeto 2 (CS012)**, tendo como cliente a **Secretaria Executiva de Vigilância em Saúde (SESAU)**.

O projeto é um MVP em **C#/.NET** que automatiza o processamento dos arquivos `.xlsx` exportados pelo I/CAD.

---

## SOLUÇÃO:

### 1. Consolidação automática
Lê múltiplos arquivos `.xlsx`, padroniza colunas e formatos e reúne os dados
em uma base histórica única.

### 2. Qualidade dos dados
Identifica registros válidos, duplicados e inconsistentes durante o
processamento.

### 3. Painel de indicadores
Disponibiliza indicadores sobre o volume de ocorrências por período, tipo, bairro e distrito sanitário (os 8 distritos do Recife).
